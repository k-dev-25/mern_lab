# Lab 02 API judging

Import the collection and environment into Postman. Select `ShopKart Lab 02 - local`, start the backend on port 3000, then run the collection in order. The collection validates registration, validation errors, login plus cookie auth, `/customers/me`, logout, and the unauthenticated boundary.

## Marks covered

- Registration and validation: 25
- Login, invalid credentials, and cookie handling: 30
- Protected `/customers/me`: 30
- Logout and session clearing: 15

These API checks cover the backend contract only; the lab's React UI marks remain manual.
