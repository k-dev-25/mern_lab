# Lab 03 API judging

Import the collection and environment into Postman. Select `ShopKart Lab 03 - local`, start the backend on port 3000, and run the collection in order. The setup requests create a temporary judge user and product; the environment stores the created product ID.

## Marks covered

- Product model and validation: 15
- Create, list, and single-product APIs: 35
- Search and category filtering: 10

The collection also checks the Lab-03 API contract that product reads are authenticated in this implementation. Frontend listing/details, React routing, loading/error/empty states, code quality, and viva remain manual judging areas.
