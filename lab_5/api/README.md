# ShopKart Lab 05 API

Import `ShopKart-Lab-05-Cart.postman_collection.json` into Postman. Set `baseUrl` if the API is not running at `http://localhost:3000`, then run the collection in order. The login request sets the HTTP-only auth cookie, and the setup request creates a product for the cart checks.

Run the backend with `cd backend && npm install && npm run mongo && npm run dev`.
